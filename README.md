# Generate Password 🔐
A Python-based password generator that creates random and secure passwords using letters, numbers, and special characters. A simple project to practice Python programming and randomization.

## Project Overview
Generate Password is a Python-based application that generates random passwords using letters, numbers, and special characters.

## Features
- Generates random passwords.
- Uses letters, numbers, and special characters.
- Helps create strong and random passwords.
- Simple and beginner-friendly Python project.

## Technologies Used
- Python
- Random Module

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python generate_password.py
```

## Project Purpose
This project was created to practice Python programming concepts, randomization, and basic programming logic.
